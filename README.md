# Power BI Sales Analysis Dashboard

## Project Overview

An interactive Sales Analysis Dashboard built using **Microsoft Power BI** to explore sales performance, identify regional trends, analyze product categories, and monitor key business metrics.

The project presents sales data through interactive visualizations and KPI indicators, helping users understand business performance from multiple perspectives.

## Dashboard Pages

### 1. Sales Overview
- Key Performance Indicators (KPIs) for overall sales performance.
- Monthly sales trends.
- Region-wise sales distribution.
- Payment method analysis.
- Interactive filters for region, product category, and month.

### 2. Regional Analysis
- Sales performance across different regions.
- Regional quantity and discount analysis.
- Customer rating distribution.
- Geographical visualization of sales.

### 3. Product Category Analysis
- Category-wise sales performance.
- Product quantity analysis.
- Customer ratings across categories.
- Discount distribution and comparison.

### 4. Dashboard
- Sales target monitoring using a gauge visualization.
- Product-level sales breakdown.
- Payment method distribution.
- Sales trend analysis.

## Tools & Technologies

- **Microsoft Power BI** – Dashboard development and data visualization.
- **Power Query** – Data preparation and transformation, if applicable to the final report.
- **DAX** – Measures and calculations, where implemented.

## Key Features

- Interactive slicers and filters.
- KPI-based sales performance monitoring.
- Regional and product category analysis.
- Multiple visualization types, including bar charts, line charts, donut charts, scatter plots and maps.
- Sales target comparison.
- Multi-page dashboard navigation.

## How to Explore

1. Clone or download this repository.
2. Install Microsoft Power BI Desktop.
3. Open `Sales_Overview.pbix`.
4. Explore the different report pages.
5. Use the available slicers and filters to interact with the dashboard.

## Project Objective

The objective of this project was to apply data visualization and business intelligence concepts to sales data, transforming raw information into an interactive dashboard that supports sales performance monitoring and exploratory analysis.
